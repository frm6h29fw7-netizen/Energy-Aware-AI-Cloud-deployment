01

AI model optimisation

Pruning removes unnecessary network weights, quantisation lowers numerical precision, and knowledge distillation transfers behaviour from a large model into a smaller model. The simulator lets these methods change energy, latency, memory, and accuracy.

PruningQuantisationDistillation
02

Deployment strategy

Container-based deployment can reduce operating system overhead compared with full virtual machines. Autoscaling can reduce idle time by matching resources to demand.

VMContainerServerless
03

Monitoring approach

Cloud systems often estimate energy indirectly through CPU/GPU utilisation, memory use, execution time, request rate, and carbon-intensity assumptions. These proxy metrics help compare deployment choices when direct power readings are unavailable.

CPU proxyGPU proxyMemory
04

Evaluation trade-off

Useful evaluation compares a baseline deployment with an optimised deployment using energy, latency, accuracy, throughput, cost, reliability, and SLA indicators.
